# 高级模式：自建节点管理

## 已确认的使用场景

用户以自建节点为主，通过分享链接添加节点，偶尔更新单个节点的地址、凭据或其他连接参数。编辑应直接作用于已有节点，保留名称、顺序、监听端口和中转组引用。

## 交互方案

- 将独立的「节点导入」和「节点管理」合并成一个「节点管理」区域。
- 「添加节点」打开内联面板，支持一条或多条分享链接；验证成功后直接加入列表。
- 每条节点保留明确的「编辑」按钮，打开名称和原始分享链接编辑面板。
- 「应用修改」验证链接后原位更新；验证失败时保留输入和原节点。面板内操作更新当前订阅草稿，整份订阅仍通过页面的保存操作提交。
- 保留搜索、排序、批量编辑、删除恢复、监听端口及 ML-KEM 设置。
- 订阅和 YAML 来源维护收进「更多导入」；这类节点的编辑面板提供「编辑来源」入口。

## 数据与验证要求

- 批量添加复用节点链接来源，不为每条节点创建一个来源。
- 从已有批量来源定位单条原始链接，编辑时同步更新来源内容与节点列表，避免再次解析后旧链接恢复。
- 修改名称时同步监听端口和中转组引用；修改连接参数时保留节点位置与已有个性化设置。
- 无效输入不部分提交；编辑单个节点时只接受一条节点分享链接。
- 使用项目已映射到 Radix Colors 的语义色彩令牌。

## 验收路径

添加两条节点 → 改名并配置顺序/监听端口/中转关系 → 编辑其中一条链接 → 应用修改 → 保存并重新打开订阅，确认新链接、原顺序与配置均保留，另一条节点不受影响。
